📈 Stocky command legend

All commands run from a terminal inside the stocky folder (wherever this clone lives on this machine).

Dashboard (the app itself, while running): http://127.0.0.1:8787

Daily

CommandWhat it doesWhen to use it
npm run up Starts everything: collector + all paper sessions, auto-restarts on crash, logs to data\logs\ After a reboot, if you have not registered auto-start. Otherwise never; it starts itself

One-time setup

CommandWhat it does
powershell -ExecutionPolicy Bypass -File scripts\register-startup.ps1 Makes npm run up start automatically at Windows logon
same with -Remove at the end Undoes the auto-start

Experimenting

CommandWhat it does
npm run backtest -- --strategy sma --fast 5 --slow 20 --save Tests a strategy against collected history; --save shows it on the dashboard
add --timeframe 15 Same, but on 15 minute bars (fewer trades, less fee drag)
add --strategy buyhold The baseline every strategy must beat
npm run paper -- --strategy sma --fast 10 --slow 30 Starts paper trading a strategy with fictional money. Ctrl+C after it starts; npm run up adopts it forever
npm run reconcile -- --id sma-crossover-5-20-btc-usd Proves paper results equal backtest results on the same bars. RECONCILED = healthy

Maintenance and checks

CommandWhat it does
npm testRuns the 38 test suite
npm run typecheckType checks without building
npm run dev Collector alone in a terminal, for debugging (do not run while npm run up is running; they fight over port 8787)

Reading the dashboard

  • Green dot = healthy. Red = feed down or stalled.
  • Paper panel "vs buy & hold": positive = strategy beating doing nothing. The only score that matters.
  • Gross vs net on any backtest: the gap between them is fees + slippage. If gross is positive and net is negative, the exchange won, not the market.
  • "missing" counts are collector downtime. They are reported, never hidden.
The rule that is not a command: the app cannot place real orders. That is phase 5, and it stays locked until a strategy beats buy and hold in paper trading for weeks.
